## Java 基础

重点回顾了 ArrayList 的动态扩容，以及 HashMap 的数组、链表与红黑树结构。链表长度达到阈值且数组容量足够时，桶会树化；扩容时，元素会保留在原位置或移动到「原位置 + 旧容量」。

## Redis 与 MySQL

Redis 更适合承接高频读取和快速状态切换，而不是替代数据库。常见的一致性方案是先更新数据库再删除缓存；对于更高一致性要求的场景，可结合 binlog 订阅实现最终一致性。
